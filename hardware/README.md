# Hardware

This folder is reserved for **approved-for-publication** electrical schematics, PCB files, wiring diagrams and component images from the Go Baby Go project.

No original shared-team hardware files have been copied into this repository.

For documented architecture, see [System Architecture](../docs/SYSTEM_ARCHITECTURE.md) and [Technical Notes](../TECHNICAL_NOTES.md). Do not treat conceptual diagrams as complete verified wiring instructions.
